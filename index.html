Qué necesitas

  • Un celular con Android 7.0 o superior.
  • Conexión a internet y una cuenta (correo, Google o Facebook).
  • Permiso para usar la cámara.
  • Espacio libre para el archivo (unos 140 MB).

Cómo instalarla

  1. Descarga el archivoToca «Descargar APK» desde tu celular Android. Si lo descargas en el computador, pásalo al celular.
  2. ÁbreloAbre el archivo desde las notificaciones o la carpeta Descargas.
  3. Permite la instalaciónSi Android lo pide, activa «Permitir de esta fuente» para tu navegador o gestor de archivos.
  4. Instala y abre la appToca «Instalar». Al abrirla, permite el acceso a la cámara para reconocer las señas.

Para actualizar, descarga la versión nueva e instálala encima: tus datos se conservan.
